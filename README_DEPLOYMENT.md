## 🚀 Deploy in 3 Steps

### **Step 1: Create GitHub Account**
Go to: https://github.com/signup

### **Step 2: Push Your Code**
Open terminal and run:
```bash
cd /Users/tejasavayadav/Desktop/schooloo.ai-main
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/schooloo-ai.git
git push -u origin main
```

### **Step 3: Deploy to Vercel**
- Go to: https://vercel.com/signup
- Connect GitHub
- Import your repository
- Set environment variables
- Click Deploy

**That's it!** Your app will be live at:
```
https://schooloo-ai.vercel.app
```

## 🆘 If Something Goes Wrong

### **Local Development**
- Check: **LOCAL_SETUP_GUIDE.md**
- Run: `bash start_local.sh`
- Kill & restart: `pkill -9 -f python3 || true && bash start_local.sh`

### **Deployment Issues**
- Check Vercel logs: Dashboard → Deployments → View Logs
- Verify environment variables: Dashboard → Settings
- Rebuild: Deployments → Click "..." → Redeploy

### **Quick Help**
- See: **VERCEL_QUICK_DEPLOY.md** → Troubleshooting section
